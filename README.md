# WSD-Pro v2

بيئة تطوير ذاتية الاستضافة: كل مشروع في حاوية معزولة خاصة به، مع محرر IDE موحّد، وواجهة opencode الرسمية بنموذج **Big Pickle** المجاني (Zen)، ودردشة للتصميم والتخطيط عبر `qwen3:30b` على Ollama Cloud.

> لا حاجة لدومين أو SSL — يعمل مباشرة عبر `docker compose` ويفتح في المتصفح بدون تسجيل دخول.

## المميزات

- **لوحة تحكم بلا تسجيل دخول** — أنشئ المشاريع، أوقفها/شغّلها، احذفها.
- **محرر IDE موحّد** (code-server) يرى **كل** المشاريع تحت `/workspaces`، بكلمة مرور ثابتة (افتراضي `admin123`).
- **opencode** — واجهة opencode **الرسمية** (النافذة الافتراضية) من الشريط الجانبي، بنموذج **Big Pickle** المجاني من Zen، تعمل من `/workspaces`.
- **دردشة التصميم** — `qwen3:30b` على Ollama Cloud للفكرة والبنية والتخطيط فقط (لا يعدّل ملفات).
- **رفع ملفات** إلى أي مشروع موجود (`/workspaces/<slug>`).
- **معاينات** — منافذ المشروع تُعرض كروابط مباشرة تُفتح في متصفحك.

## البنية

| الحاوية | الدور |
| --- | --- |
| `app` | اللوحة (:3000) + محرر IDE (:8100) + opencode web (:4096) + الدردشة |
| `workspace` | الصورة الأساسية `wsd/workspace:latest` التي تُبنى منها حاويات المشاريع |

حاويات المشاريع تُنشأ ديناميكيًا عبر مقبس Docker من خلفية `app`، كل واحدة على منافذها المحددة، مع مشاركة مجلد `./workspaces`.

## التشغيل السريع

```bash
cp .env.example .env        # ضع OLLAMA_API_KEY + OPENCODE_API_KEY (Zen مجاني)
docker compose build
docker compose up -d
```

ثم افتح `http://<IP>:3000`. المحرر على `http://<IP>:8100` بكلمة المرور من زر **Web IDE**، وopencode على `http://<IP>:4096` أو من زر **opencode** في الشريط الجانبي.

انظر [docs/INSTALL.md](docs/INSTALL.md) للتفاصيل الكاملة.
