# WSD-Pro v2

بيئة تطوير ذاتية الاستضافة: كل مشروع في حاوية معزولة خاصة به، مع محرر IDE موحّد، ووكلاء بناء عبر opencode، ودردشة للتصميم والتخطيط — كلها بنموذج **مجاني واحد** (`qwen3:30b` على Ollama Cloud).

> لا حاجة لدومين أو SSL — يعمل مباشرة عبر `docker compose` ويفتح في المتصفح بدون تسجيل دخول.

## المميزات

- **لوحة تحكم بلا تسجيل دخول** — أنشئ المشاريع، أوقفها/شغّلها، احذفها.
- **محرر IDE موحّد** (code-server) يرى **كل** المشاريع تحت `/workspaces`، محمي بكلمة مرور تُعرض في اللوحة.
- **opencode** — لوحة بناء داخل كل مشروع تشغّل `opencode run` وتبثّ الناتج مباشرة، مع خاصية `--continue` للحفاظ على سياق الجلسات.
- **دردشة التصميم** — `qwen3:30b` على Ollama Cloud للفكرة والبنية والتخطيط فقط (لا يعدّل ملفات).
- **رفع ملفات** إلى أي مشروع موجود (`/workspaces/<slug>`).
- **معاينات** — منافذ المشروع تُعرض كروابط تشغّل فورًا.

## البنية

| الحاوية | الدور |
| --- | --- |
| `app` | اللوحة (:3000) + محرر IDE (:8100) + opencode + الدردشة |
| `workspace` | الصورة الأساسية `wsd/workspace:latest` التي تُبنى منها حاويات المشاريع |

حاويات المشاريع تُنشأ ديناميكيًا عبر مقبس Docker من خلفية `app`، كل واحدة على منافذها المحددة، مع مشاركة مجلد `./workspaces`.

## التشغيل السريع

```bash
cp .env.example .env        # ضع OLLAMA_API_KEY
docker compose build
docker compose up -d
```

ثم افتح `http://<IP>:3000`. المحرر على `http://<IP>:8100` وكلمة مروره تظهر عند زر **Web IDE** في اللوحة.

انظر [docs/INSTALL.md](docs/INSTALL.md) للتفاصيل الكاملة.
